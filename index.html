    4. Mapa de cobertura

    Geocodifica cada CEP (com cache local para nunca reconsultar o mesmo CEP duas vezes) usando fontes brasileiras gratuitas — AwesomeAPI CEP como principal, CEP Aberto como reserva opcional — e agrupa os resultados por bairro: o mapa marca só os bairros que aparecem na sua lista de CEPs, um marcador por bairro. Em listas de faixas de CEP, as duas pontas de cada faixa entram no agrupamento, então uma faixa pode acrescentar mais de um bairro. Só os CEPs são enviados a essas APIs públicas para desenhar o mapa; a geração das planilhas continua 100% local.

    Cole os CEPs acima e clique em "Atualizar mapa".
